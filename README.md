There is no website manager skill or MCP server in the Claude ecosystem (Cowork, Claude Code, or Claude.ai) that lets a non-technical user manage a personal blog through natural language. Mataroa is an ideal first target: it is a hosted, minimal blogging platform with a clean REST API, zero local toolchain requirements, and no rate limiting. No existing Mataroa MCP server exists anywhere (confirmed via GitHub, MCP registries, and Anthropic connector directory as of June 2026).
The goal is to build an MCP server that bridges Claude and the Mataroa API so a user can say things like "publish a new post about my weekend trip" or "show me all my drafts" and have Claude execute those actions directly.
